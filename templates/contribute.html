Create a page yourself

Fork the repository and run the generator below from its root. It creates a draft for any of the five page types. Replace the placeholders, cite public sources and open a pull request. The ID is the permanent URL slug.

python -m pip install -r requirements.txt
python tools/new_entry.py problem my-problem --title "My problem"
python tools/validate.py
python tools/verify_refs.py --strict
python tools/build.py
python tools/check_site.py

Read the step-by-step contributor guide and page schema and evidence rules. The issue routes require a GitHub account; the site does not currently have a no-account submission form.

Use an agent

Give your agent a specific question or page ID, ask it to read AGENTS.md, and have it cite the sources behind every change. It can read the whole catalogue from index.json or llms.txt. Agent-authored changes use the same pull request and human review process. There is no remote write API or automatic research bot yet.

For a concrete starting task, use the machine-readable review queue or an open question. A research result should first be made citable as a preprint, paper or reproducible public report; an issue or PR then links the result to the relevant page.
